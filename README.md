# LP制作サービス サンプルLP

個人事業主・フリーランス専門LP制作サービスのサンプルLP。

## 概要

- キャッチコピー: 「5,000円以下・最短3日で。個人事業主・フリーランス専門のLP制作サービス。」
- 公開先: Vercel
- 技術: HTML / CSS（レスポンシブ対応）

## ファイル構成

```
lp-service-sample/
├── index.html         # LP本体
├── style.css          # スタイルシート
├── images/            # 画像フォルダ
├── requirements.md    # 要件定義書
├── design.md          # 設計書
├── image-prompts.md   # NanoBanana2画像プロンプト集
└── README.md
```

## Vercelへのデプロイ手順

1. GitHubにpushする
2. Vercel（vercel.com）にログイン
3. 「Add New Project」→ このリポジトリを選択
4. そのままデプロイ（設定不要）
