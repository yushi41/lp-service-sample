# LP制作サービス_サンプルLP 要件定義書
作成日: 2026-03-09

---

## 1. プロジェクト概要

クラウドソーシング（クラウドワークス・ランサーズ）での案件獲得を目的とした
LP制作サービスの「自社サンプルLP」を制作する。

---

## 2. 目的・ゴール

- GitHub Pagesで公開し、クラウドワークスのプロフィールURLとして使用する
- 「この人に頼みたい」と思わせる信頼感と価格の明確さを伝える
- 問い合わせ導線（クラウドワークスのメッセージへ誘導）を作る

---

## 3. ターゲット（LPを見る人）

- 個人事業主・フリーランス
- 自分でLPを作れない・作る時間がない
- 低予算（〜5万円未満の感覚）
- 「まずは試したい」という温度感

---

## 4. 機能要件

### コンテンツ
- [ ] ヒーローセクション（キャッチコピー + CTA）
- [ ] 課題提起（ターゲットの悩みを3つ）
- [ ] サービス紹介（何ができるか）
- [ ] 選ばれる理由3点
- [ ] 料金プラン（シンプル1プラン）
- [ ] 制作の流れ（4ステップ）
- [ ] FAQ（4〜5問）
- [ ] 最終CTA（お問い合わせ）

### 技術
- [ ] HTML/CSS単一ファイル（index.html）
- [ ] レスポンシブ対応（スマホ優先）
- [ ] GitHub Pagesで公開可能な構成
- [ ] 画像はNanoBanana2/NanabananaProで生成・埋め込み

---

## 5. 非機能要件

- 表示速度：画像は軽量化（WebP推奨）
- デザイン：信頼感・プロっぽさを重視
- 文字量：読みやすく・詰め込みすぎない

---

## 6. 制約

- 実績0件なので「実績」セクションは作らない
- 代わりに「サンプル制作物」として今回のLP自体を実績として使う予定
- 運営者情報：仮名でOK（後で本名・SNSリンクに差し替え）

---

## 7. 今後の展開

- 実績5件獲得後：料金をBプラン（1万〜3万円）に値上げ
- 将来的に：クラウドワークス → ダイレクト受注 → 月5〜10万円を目指す
