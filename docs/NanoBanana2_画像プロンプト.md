# NanoBanana2 / NanabanaPro 画像生成プロンプト集
作成日: 2026-03-09

このファイルのプロンプトをそのままNanoBanana2に貼り付けてください。
生成した画像は `images/` フォルダに保存してください。

## 画像① ヒーロー画像（hero.webp）
保存先: `images/hero.webp`
推奨サイズ: 1920×1080px（16:9）

```
横長（16:9）のLP用ヒーロー画像を作成してください。

【デザインイメージ】
ディープネイビー（#1a2744）からダークパープルへのグラデーション背景。
プロフェッショナルでスタイリッシュな雰囲気。

【中央に配置するビジュアル】
ノートPCの画面にきれいなランディングページが表示されている様子。
画面の光が周囲をほんのり照らしている。
右側にスマートフォンも添えて、レスポンシブ対応を示す。

【デザイン要素】
・背景に薄いグリッド線やドット模様（テック感）
・ゴールド/アンバー（#f5a623）のアクセントライン
・余白多め・シンプル・高級感

【雰囲気】
ビジネス・テック系・清潔感・信頼感
```

## 画像② アイコン3点セット（icon-1〜3.webp）
保存先: `images/icon-1.webp` / `images/icon-2.webp` / `images/icon-3.webp`
推奨サイズ: 200×200px（1:1）

```
シンプルなフラットデザインのアイコンを3つ作成してください。
背景：オフホワイト（#f8f9fa）
線・図形の色：ディープネイビー（#1a2744）またはゴールド（#f5a623）

アイコン1（icon-1）：稲妻マーク（スピード・高速を表す）
アイコン2（icon-2）：吹き出しと鉛筆（コピーライティング・言葉を表す）
アイコン3（icon-3）：ハートまたは握手（丁寧な対応・信頼を表す）

・ミニマル・余白多め・線は細め
・3つ統一感のあるデザイン
・正方形（1:1）で出力
```

---

## 使い方メモ

1. NanoBanana2を開く
2. 上記プロンプトをコピーして貼り付けて生成
3. 生成された画像をダウンロード
4. `images/` フォルダに保存（ファイル名を上記の通りに変更）
5. index.html の img src が正しいパスを参照しているか確認
