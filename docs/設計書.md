## 6. Vercel公開手順（実装後）

1. GitHubで新規リポジトリ `lp-service-sample` を作成
2. `index.html` と `images/` をプッシュ
3. Vercelにログイン → 「Add New Project」→ GitHubリポジトリを選択
4. 設定はデフォルトのままで「Deploy」をクリック
5. 公開URL：`https://lp-service-sample.vercel.app`（自動発行）
6. クラウドワークスのプロフィールに掲載

※ GitHubにプッシュするたびに自動で再デプロイされる
